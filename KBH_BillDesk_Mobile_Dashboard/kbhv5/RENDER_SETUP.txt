KBH BillDesk Mobile Dashboard - Render Setup

Build Command:
pip install -r requirements.txt

Start Command:
PLAYWRIGHT_BROWSERS_PATH=0 python -m playwright install chromium && PLAYWRIGHT_BROWSERS_PATH=0 gunicorn web_app:app

Environment variable:
KBH_WORKERS=40

Root Directory:
If these files are at the repository root, leave blank.
If the kbhv5 folder is the repository root, use kbhv5.

Do not use `--with-deps` on Render.

Dashboard behavior:
- Selected month controls the student list and amount summary.
- Column C (ROLL NO) is used for student matching.
- Column E (RECIEPT ID), F (DATE), G (PAID), and H (AMOUNT) are the payment fields.
- Paid Amount = SUM of H for rows whose G is PAID.
- Pending Amount = SUM of H for rows whose G is not PAID.
- Total Amount = SUM of H for all students in the selected month.
- Update NOT PAID Students checks only NOT PAID records for the selected month on BillDesk.
- A successful BillDesk payment is written back to that selected month's sheet with PAID, amount, date, and reference.

If the sheet contains a fee column (Fee, Fee Amount, Monthly Fee, Mess Fee, Food Fee, Total Fee, Amount Due, Due Amount, Payable Amount, or Total Amount), that value is used per student. If no fee column exists, KBH_MONTHLY_FEE from Apps Script properties is used; the default is ₹4800.
